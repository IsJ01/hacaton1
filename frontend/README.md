# Фронт «Эко-Щит Каспия» — дашборд инспектора

Чистый HTML + JS + Leaflet, без сборки и без npm.

## Запуск

1. Поднять бэкенд на 8001 (мок: `bash docker.sh mock` или `bash run_mock.sh` в `mock-backend`).
2. В этой папке: `bash run.sh`
3. Открыть http://localhost:3000

## Заглушки и настройки — `js/config.js`

- `USE_MOCK: true` — работать без бэкенда, на данных из `js/mock.js`.
- `API_BASE` — адрес бэкенда (по умолчанию тот же хост, порт 8001).
- `CRITICAL_SOUND_LABELS`, `CRITICAL_WATER_TYPES` — что считать критическим событием.
- `INCIDENT_WINDOW_MIN`, `INCIDENT_RADIUS_KM` — какие сигналы склеиваются в один инцидент.
- `ACTIVE_ALERT_MIN`, `BUOY_ONLINE_MIN` — сколько инцидент «горит» и когда буй считается без связи.
- `ZONES` — границы ООПТ (схематичные) и место подписи; `PLACES` — свои подписи на карте.
- `POLL_INTERVAL_MS` — частота обновления.

## Что считает фронт

- **Инциденты.** Критические события (лодка, выстрел, сброс), близкие по времени и месту, склеиваются
  в один инцидент. Слышали ≥2 буя или совпали буй и спутник — бейдж «Подтверждено».
- **Статус буя за сутки** приходит с бэкенда (`/api/v1/buoy-status`): синий — норма, жёлтый — аномалия,
  красный — критично; пунктир — нет связи. Круг вокруг буя — его радиус слышимости того же цвета.
  Зона ООПТ берёт худший статус своих буёв.
- **Кто ещё слышал**: клик по любому событию открывает окно с соседними буями (`/neighbors`).
  Никто из соседей не слышал — «возможно ложное срабатывание».
- **Что происходило рядом**: в окне события — лента времени по буям и таблица всех событий в ±2/5/15 мин
  (`/context`); клик по точке или строке открывает то событие.
- **Гибель тюленей** (вкладка): находки туш, форма «+ Находка» (место можно указать на карте), отчёт
  расследования — вывод, версии с уликами, что проверить, дрейф на карте до вероятного места гибели, землетрясения.
- **Тюлени** (слой на карте, `/api/v1/seals`): где слышны, оценка численности, трек и стрелка дрейфа.
- **Алерты**: всплывающее уведомление со звуком и пульсирующая метка на карте при новом инциденте.
- **Карточка инцидента**: сигналы, спектрограмма (считается в браузере, `js/spectrogram.js`), плеер,
  решение инспектора (хранится в `localStorage`) и «Скачать акт» — печатная страница → PDF.
- **Режим демо** (галочка в шапке) показывает кнопки записи звука и запуск сценария «браконьер».

## Файлы

- `index.html` — разметка: 5 вкладок (Карта, Инциденты, Все события, Прогноз, О системе) + правая панель с буями.
- `js/config.js` — настройки. `js/mock.js` — данные-заглушки. `js/api.js` — запросы по контракту v2.
- `js/app.js` — вся логика интерфейса. `js/spectrogram.js` — спектрограмма звука. `css/style.css` — стили. `vendor/leaflet` — карта (локально).

## Запись звука

Кнопка «Записать звук» работает на `localhost` или по https (ограничение браузера).
С телефона по http — кнопка «Файл» (телефон предложит диктофон или файл).
Запись отправляется в `POST /api/v1/classify/upload` (поля `file`, `buoy_id`).
